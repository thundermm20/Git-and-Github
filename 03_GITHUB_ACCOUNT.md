# Github Account
&bull; Create a new repository

    Step-1: Click on New(Repository) in Dashboard
    Step-2: Select Owner/Enter Repository name. Enter Description(Optional)
    Step-3: Select Private/Public
    Step-4: Initialize README file if want
    Step-5: Click Create Repository
&bull; Commit
Before Finalizing commit is done. Then Finalized</br></br>
<b>Making Commit</b></br>
File is commited after editing file or adding files.

    Step-1: Click on Edit icon(Pencil like). README.md for example
    Step-2: Click Commit Changes to take screenshots(for history)
    Step-3: Write Commit Message, Commit Description(Optional), Select option.
    Step-4: Click on Commit Changes to finalize
